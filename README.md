🌍 WeatherWorld; https://tanutechlab.github.io/Global-Weather-forecast/

A responsive weather forecasting website that lets users explore real-time weather conditions and a 7-day forecast for cities 
around the world. Built using HTML, CSS, and JavaScript.

✨ Features;
🌎 Worldwide City Search — Search for cities across the globe.
🌡️ Live Weather Updates — View current temperature and weather conditions.
📅 7-Day Forecast — Check daily weather conditions and temperature highs and lows.
💧 Humidity Information — View current relative humidity.
💨 Wind Speed — Check wind speed in your selected city.
🌧️ Rain Probability — View the forecast probability of precipitation.
☀️ UV Index — Check the daily maximum UV index.
🔄 Temperature Conversion — Switch between Celsius and Fahrenheit.
📍 Current Location — Get weather information using your device's location.
🏙️ Popular World Cities — Explore weather in eight popular cities.
📱 Responsive Design — Works on desktops, tablets, and mobile devices.

🛠️ Technologies Used;
HTML,
CSS,
JavaScript.

🌦️ Explore the weather, anywhere in the world!
